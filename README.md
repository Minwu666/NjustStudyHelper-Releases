# 理迹 · 安装与更新

理迹是面向南京理工大学学生的非官方学习辅助 Android 应用。本仓库用于发布安装包和版本说明。

## 下载

在 [Releases](https://github.com/Minwu666/NjustStudyHelper-Releases/releases) 下载最新正式版的 `liji.apk`。

已安装旧版时，请直接覆盖安装，**不要先卸载**，账号、课表和样式设置会保留。安装包使用同一发布密钥签名。

## 应用内更新

从 1.1.0 起，在「设置 → 应用更新」可以：

- 手动检查并下载新版本。
- 选择每 6/12 小时检查，或每天指定时间检查，也可关闭自动检查。
- 设置仅 Wi-Fi 下载，下载完成后点击通知或在应用内安装。

默认每天 12:00 左右检查、仅 Wi-Fi 下载。后台检查可能因系统省电或网络延后。安装需要 Android 系统确认，第一次可能需要允许理迹安装应用。

旧版 1.0 尚无更新功能，需要先手动覆盖安装一次 1.1.0。之后可通过应用内更新升级。

## 发布约定

正式标签使用 `v主版本.次版本.修订号`（如 `v1.1.0`），APK 附件固定名为 `liji.apk`。每次发布递增 Android `versionCode` 和 `versionName`，继续使用原签名密钥。草稿和预发布不会用于自动更新。

客户端会校验下载来源、文件大小、GitHub 提供的 SHA-256、包名、版本与应用签名。GitHub 网络不可达时可以稍后重试。
